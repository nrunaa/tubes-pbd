# Goods Sales & Distribution Monitoring

Repositori ini berisi hasil pengerjaan tugas mata kuliah Pemodelan Basis Data, Program Studi Informatika, Telkom University. Proyek ini difokuskan pada perancangan dan implementasi basis data untuk sistem penjualan dan distribusi barang dengan studi kasus PT Ratu Sedunia.

Sistem basis data ini dirancang untuk mengelola keseluruhan data operasional perusahaan, yang mencakup pendataan produk, pemantauan stok barang di setiap outlet, pengelolaan data tenaga penjualan (sales), serta pencatatan riwayat pemesanan dan transaksi pembayaran.

## 📂 Penjelasan File
* **`tubes2_tabel.sql`** : Script DDL (Data Definition Language) untuk membuat dan mendefinisikan struktur tabel basis data.
* **`tubes3_dummy.sql`** : Script DML (Data Manipulation Language) yang memuat data pengujian (dummy) untuk mengisi tabel.
* **`tubes4.sql`** : Script DQL (Data Query Language) yang berisi 6 instruksi query spesifik untuk menghasilkan laporan operasional studi kasus.
* **`clasicmodel.sql`** : File dataset tambahan pendukung proyek.
